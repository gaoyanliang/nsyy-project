#11 设备
###/equip_disp/<equip_page>/
request: (get)  
return:  
```
"data":{
#公开参数，可编辑
"equip_name":str 名称
"equip_code":str 编码
"equip_type_id"：int 类别
"equip_mod":str 型号
"equip_size":str 尺寸
"equip_start_date":date 投用时间
"equip_life":int 使用寿命
"equip_loca":str 位置
"equip_supplier":str 供应商
"equip_maint": str 维护人员
"equip_photo": base64照片
}
```
###/equip_manage
request:(post)  
```
{
"token": token,
"disp_col": [col, col] 展示列
"disp_page": int 页数
"disp_no_page": int 每页显示数量
}
```
return:
```
"data":{
#列取决于request
#公开参数，可编辑
"equip_name":str 名称
"equip_code":str 编码
"equip_type_id"：int 类别
"equip_mod":str 型号
"equip_size":str 尺寸
"equip_start_date":date 投用时间
"equip_life":int 使用寿命
"equip_loca":str 位置
"equip_supplier":str 供应商
"equip_maint": str 维护人员
"equip_photo": base64照片
#不公开数据，可编辑
"equip_pro_date":date 采购时间
"equip_supplier_contact":str 供应商联系方式
"equip_cont": base64 合同
"equip_stn":str 工位
"equip_price":double 价格
"gp_name": [str, str, str] 设备组（可能多个，科室选择方式）
#不公开，不可编辑
"equip_page":str 页面
"total_qty": int 总数量
}
```
